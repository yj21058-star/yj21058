스터디온 UI/UX 중간고사 업로드 안내

1. https://github.com/yj21058-star/yj21058 에서 Add file → Upload files를 누릅니다.
2. ZIP을 먼저 압축 해제합니다. ZIP 자체를 올리지 않습니다.
3. index.html, style.css, script.js, README.md 4개를 저장소 최상위에 업로드합니다.
   기존 assets/images/service.svg는 그대로 유지합니다.
4. 커밋 메시지: 중간고사 - 학습 계획 보관 및 완료 관리
5. Commit changes를 누릅니다. 기존 Pages 설정은 그대로 사용합니다.
6. Actions의 Pages 배포 완료 후 https://yj21058-star.github.io/yj21058/ 를 엽니다.
7. 완료 화면에 '내 계획에 보관' 버튼, 하단에 '내 계획 보관함'이 보이면 새 버전입니다.
8. README의 배포 후 체크리스트를 실제 확인하고 결과를 README에 기록합니다.

제출 입력 예시
GitHub 저장소: https://github.com/yj21058-star/yj21058
배포 웹페이지: https://yj21058-star.github.io/yj21058/
README: https://github.com/yj21058-star/yj21058/blob/main/README.md

이 버전은 업로드 전입니다. 실제 배포 화면을 확인한 뒤 제출하세요.
