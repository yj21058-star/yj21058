# 스터디온 · 5주차 사용자 행동에 반응하는 웹페이지

4주차 스터디온 반응형 페이지를 이어서 수정했습니다. 기존 서비스 소개, 기능 카드, 이용 방법, 이미지, 내부 이동 메뉴를 유지하고 학습 계획 확인 기능을 추가했습니다.

## 추가한 기능
- 외부 script.js를 defer로 연결하고 querySelector로 요소 선택
- submit 이벤트에서 confirmPlan 함수를 실행하고 preventDefault로 페이지 이동 방지
- const/let 변수, if 조건문, 함수와 이벤트 처리 사용
- 공백만 있는 과목/목표를 검사하고 오류 안내와 입력창 강조, 포커스 이동
- 이메일은 선택이며 입력한 경우 이메일 형식 검사
- 정상 입력 시 계획 요약과 초록색 성공 안내, 확인 완료 버튼 비활성화
- 입력 수정 시 결과를 숨기고 확인 버튼 다시 활성화
- 다시 입력 버튼으로 입력·안내·결과·버튼 상태 초기화
- 입력 내용은 textContent로만 표시. 서버 저장, 전송, 메일 발송 없음
- 4주차의 Grid, 유동 너비, 768px 미디어 쿼리 유지

## 실행
압축을 풀고 index.html을 브라우저로 엽니다. index.html, style.css, script.js, assets 폴더를 같은 구조로 유지합니다.

## 확인 방법
1. 빈 상태에서 계획 확인 → 과목 오류 문구와 강조
2. 과목만 입력 → 목표 오류 문구
3. 과목/목표와 잘못된 이메일 입력 → 이메일 오류
4. 정상 과목/목표, 이메일 생략 또는 정상 이메일 → 계획 요약, 성공 안내, 버튼 비활성화
5. 입력 수정 → 이전 결과 숨김과 버튼 활성화 → 다시 확인 가능
6. 다시 입력 → 모든 입력과 요약 초기화
7. 1100px, 768px, 390px에서 화면 잘림·가로 스크롤 없이 보이는지 확인

제작 중 확인: JavaScript 구문 검사 및 DOM 모형을 이용한 조건·상태 전환 테스트 통과. HTML 연결·내부 링크·이미지 경로 검사 통과.
실제 브라우저에서의 PC/모바일 레이아웃, 이메일 브라우저 검증, 배포 후 두 URL 접속은 업로드 후 확인해야 합니다.
