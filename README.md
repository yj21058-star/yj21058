# 스터디온 · 7주차 사용자 흐름과 인터랙션 시나리오

## 서비스 소개
- 주요 사용자: 일과 학업을 병행하는 온라인 대학생
- 서비스 목적: 강의·과제 일정을 고려해 실천 가능한 주간 학습 계획을 준비한다.
- 기존 기능: 서비스 소개와 이미지, 기능 3개, 이용 방법, 내부 이동, 과목·목표·이메일 입력, 입력 검증, 반응형 화면을 유지한다.
- 데이터 범위: 현재 화면에서만 동작하는 프런트엔드 실습이다. 새로고침 시 입력이 사라진다. 서버 저장·계정·이메일 발송 기능은 없다.

## 파일
- `index.html`: 서비스 소개와 학습 도구, 학습 계획 화면
- `style.css`: 기존 반응형 디자인과 탭·피드백·진행 상태 스타일
- `script.js`: 이벤트 처리와 상태 전환
- `assets/images/service.svg`: 학습 계획 예시 이미지

## 학습 도구의 이벤트
| 동작 | 이벤트 | 화면 변화 |
| --- | --- | --- |
| 계획 가이드·학습 시간·준비 점검 탭 선택 | click | 선택 탭의 색상/aria-selected 변경, 연결된 패널 하나만 표시 |
| 과목·목표 입력 | input | 필수 입력 안내와 성공 스타일 변경, 목표 글자 수 표시 |
| 하루 학습 시간 선택 | change | 주 5일 총시간 안내, 성공 스타일, 준비 버튼 활성화/문구 변경 |
| 시간 준비 버튼 | click | 준비 안내, 버튼 문구와 비활성화 상태 변경 |
| 준비 점검 버튼 | click | 준비/취소 상태와 문구·스타일·aria-pressed 변경 |

탭은 좌우 방향키·Home·End로도 이동한다. 입력 오류는 aria-invalid와 텍스트로 안내하고 해당 입력으로 초점을 이동한다. 사용자 입력은 textContent로 표시한다.

## 사용자 목표와 완료 조건
- 사용자 목표: 이번 주 학습할 과목과 구체적인 목표, 하루 학습 시간을 정한다.
- 핵심 행동: 필수값을 입력·선택하고 내용을 확인한 뒤 계획을 확정한다.
- 완료 조건: 관심 과목·목표·학습 시간이 유효하고, 확인 화면에서 ‘계획 확정’을 눌러 완료 화면과 최종 요약이 표시된다.
- 6주차의 학습 도구 탭·입력 피드백·시간 선택·준비 점검을 유지했다. 시간 준비 버튼을 계획 입력 단계와 연결했다.

## 사용자 흐름 (4단계)
1. 시작: 목표와 완료 조건을 읽고 ‘학습 계획 시작’을 누른다.
2. 입력·선택: 과목·목표·시간을 지정한다. 이메일은 선택이다. ‘다음: 계획 확인’에서 유효성을 검사한다.
3. 확인: 과목·목표·하루 및 주간 시간·이메일을 읽는다. ‘이전: 내용 수정’으로 돌아가도 값이 유지된다. 변경 후 다시 확인하면 새 값이 반영된다.
4. 완료: ‘계획 확정’으로 완료 안내와 요약을 표시한다. ‘다시 시작’은 입력·선택·오류·확인 결과·진행 단계 및 연결된 학습 도구 상태를 초기화한다.

## 인터랙션 시나리오
| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 학습 계획 시작 | click | 시작 단계 | 입력 화면과 2단계 표시 | 입력·선택 |
| 과목·목표 작성 | input | 입력 내용 변경 | 글자 수·입력 안내·스타일 갱신 | 입력·선택 |
| 학습 시간 지정 | change | 20/40/60분 선택 | 필수값 안내 갱신 | 입력·선택 |
| 다음: 계획 확인 | submit | 필수값 누락 또는 잘못된 이메일 | 수정 방법·오류 표시, 오류 입력에 초점 | 입력·선택 유지 |
| 다음: 계획 확인 | submit | 입력 유효 | 입력값을 요약에 반영 | 확인 |
| 이전: 내용 수정 | click | 확인 단계 | 입력값 유지, 수정 화면 표시 | 입력·선택 |
| 이전: 시작 | click | 입력 단계 | 값을 지우지 않고 시작 화면 표시 | 시작 |
| 계획 확정 | click | 확인 단계이며 검증한 계획 존재 | 완료 안내와 최종 요약 표시, 확정 버튼 비활성화 | 완료 |
| 다시 시작 | click | 입력 또는 완료 단계 | 입력·선택·오류·요약·단계·학습 도구 초기화 | 시작 |
| 학습 도구에서 이 시간으로 준비하기 | click | 시간을 선택함 | 선택 시간을 계획에 반영, 입력 화면 표시 | 입력·선택 |

- 세 너비에서 이전 단계 값 유지 → 목표·시간 수정 → 확인 요약 갱신 → 완료 → 다시 시작 테스트 통과.
- 필수 시간 누락 시 확인 단계 진입 차단: 통과.
- 완료 이후 시간 도구로 다시 계획 수정·확정: 통과.
- 시작으로 돌아갔다가 재진입 시 값 유지: 통과.
- 다시 시작 시 연결된 학습 시간 선택과 준비 점검 상태까지 초기화: 통과.
